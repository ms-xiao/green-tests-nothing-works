One excuse, under 140 characters, that an AI agent gives for why its unit
tests are all green while the product does nothing. A comedy-editor judge
reads the excuses two at a time and keeps the funnier, fresher one — the
joke has to land on its own, with no setup and no second sentence.

**The line** (94 characters):

> The tests are green because the app never does anything wrong — it never does anything at all.

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted.
